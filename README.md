# BelEye
A lightweight, modern desktop app for viewing RTSP IP cameras. Built with Python, PySide6 and FFmpeg — auto-arranging grid, single-camera focus, drag-and-drop reordering, low-latency playback, auto-reconnect, and a clean dark UI. Credentials live in the OS keyring, not in JSON. Cross-platform: Linux (Wayland + X11), Windows, macOS.
